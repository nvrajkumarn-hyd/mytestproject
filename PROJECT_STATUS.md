# Giftora Project Status

## Included in this downloadable version

- Complete premium storefront architecture (45 page routes, including dynamic product/category/recipient/occasion pages)
- 42 mock products
- Product categories and occasion routes
- Recipient routes
- Product details with personalisation UI
- Location / delivery selection UI
- Cart and wishlist persisted in browser localStorage
- Checkout demonstration
- Order confirmation
- Order tracking demonstration
- Gift reminders
- Account pages
- Corporate gifting
- Admin dashboard
- SEO support
- Mobile-first responsive layouts
- One-click Windows launcher

## Demo / mock behavior

This project intentionally uses mock product availability, ratings, delivery checks, account data, order statuses and admin data. These must be replaced by real backend data before commercial use.

## Security note

Do not store uploaded personalisation photos, customer addresses, payment data or credentials in public frontend files. Use private backend storage, signed access and server-side authorization.

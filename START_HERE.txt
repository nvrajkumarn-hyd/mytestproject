GIFTORA - SIMPLE START
======================

1. Right-click the downloaded ZIP file.
2. Choose "Extract All".
3. Open the extracted giftora-premium folder.
4. Double-click OPEN_WEBSITE.bat.
5. The first time only, wait while website files install.
6. Your browser should open automatically at:

   http://localhost:3000

IMPORTANT
---------
Keep the black Giftora window open while checking the website.
To stop the website, close that black window or press Ctrl+C.

If Node.js is missing, the launcher opens the Node.js website.
Install the LTS version, then double-click OPEN_WEBSITE.bat again.

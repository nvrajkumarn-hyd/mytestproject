# Giftora Premium Gift Marketplace

A mobile-first gifting marketplace built from the supplied Giftora master prompt.

## Technology

- Next.js 15.5.x
- React 19
- TypeScript
- Tailwind CSS
- Lucide React icons
- Next/Image
- Vercel-ready App Router architecture

## Quick local start on Windows

Double-click `OPEN_WEBSITE.bat`.

Or manually:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm start
```

## Implemented experience

- Premium responsive storefront
- Desktop mega navigation + mobile drawer
- Search-driven gift browsing
- 40+ sample products
- Occasions, recipients, categories and price discovery
- Product listing filters and sorting
- Product detail page with location check
- Delivery date and delivery-slot selection
- Personalisation fields + mock live preview
- Add-ons
- Persistent browser cart and wishlist
- Five-step checkout UI
- Order confirmation and tracking
- Gift reminders
- Customer account views
- Corporate gifting lead form
- Admin commerce dashboard
- Offers
- FAQ, about, contact and policy pages
- Sitemap and robots

## Environment variables

Copy `.env.example` to `.env.local` when connecting real services.

## Vercel deployment

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Add environment variables in Vercel Project Settings.
4. Run the production build.
5. Add your custom domain.
